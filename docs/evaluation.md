## 4. Limits and possible improvements

- **Ground truth.** The hidden class is never observed: the HMM is trained and scored on CAMS model bands. Calibrating the reading trust `r` against street-level sensors (where public ones exist) would replace an assumption with an estimate.
- **Forecast archive.** The MDP backtest feeds past model values in as the forecast. Archiving the real 3-day forecasts each day would give an honest backtest of decisions made with forecast error.
- **Richer state.** Persistence is hard to beat with first-order transitions on a slowly changing series; adding wind speed or the trend of the last hours to the state could help multi-hour predictions.
- **QMDP.** The action rule assumes the class becomes known after one step; a small POMDP solved over a discretised belief would value waiting for information properly.
- **Exposure index.** Kinds come from OSM road classes and a 25 m rule; traffic counts or measured NO2 along streets would make the cleanest route evidence-based rather than a proxy.
